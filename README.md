# Reminders

A simple task management tool for the Light Phone III.

Organize tasks into lists, add due dates and times, check things off as you go, and get notified when it matters.

---

## Features

* Organize tasks into multiple lists
* Add due dates and times to any task
* Today view shows only tasks due today
* Subtasks on any task, including when adding a new task
* Completed tasks move to a collapsible group at the bottom
* Long-press a list to rename, reorder, clear completed, or delete it
* Set recurring reminders for routine tasks
* Alerts at a task's due time open the tool so you can complete it or remind yourself later, plus an optional morning summary

---

## Data and privacy

Everything is stored on the phone and the tool works fully offline. Nothing leaves the device unless you choose to sign in to sync to [Reminders Web](https://github.com/zacksimpson/reminders-web). There are no analytics, tracking, or advertising.

If you sign in, your email address and password go to Google Firebase Authentication, and your lists, tasks and settings are stored in a Firestore database in a Firebase project run by the developer (same account as the Reminders web app). Syncing runs when the tool opens and about every 30 minutes while you are signed in and online. Signing out stops syncing.
